Introduction à Python — Master 1 Économie du travail et ressources humaines

Vous n’en avez probablement pas besoin. Le cours s’exécute directement dans votre navigateur, sans rien installer : retour aux notebooks en ligne. Cette archive sert à travailler sans connexion, ou pour le projet de groupe si vos données dépassent ce que le navigateur peut traiter.
Télécharger cours-python-etrh.zip Les cinq séances, les corrigés, les jeux de données et le lanceur

Utilisation

Il vous faut Python 3 installé. Sous Windows, cochez bien Add Python to PATH pendant l’installation.

Décompressez l’archive, ouvrez un terminal dans le dossier obtenu, puis :

python cours.py

Sous Windows, c’est parfois py cours.py. Au premier lancement, le programme installe ce qu’il faut — comptez une minute — puis ouvre le cours dans votre navigateur via JupyterLab. Les fois suivantes, c’est immédiat.

* Pourquoi Python pour un économiste du travail ?

Vous savez déjà faire des statistiques descriptives. La question n'est donc
pas /ce/ que Python calcule, mais /pourquoi/ passer par du code plutôt que
par un tableur.

*La reproductibilité.* Dans un tableur, une analyse est une suite de gestes :
un clic ici, un tri là, une formule recopiée jusqu'en bas. Six mois plus tard,
personne — pas même vous — ne peut dire exactement ce qui a été fait. Un
script, lui, /est/ la description exacte de l'analyse. On le relit, on le
corrige, on le relance sur des données actualisées, on l'envoie à un collègue
qui obtient le même résultat. C'est ce qu'on attend aujourd'hui d'un mémoire
comme d'un rapport d'étude.

*Le passage à l'échelle.* Un tableur devient pénible au-delà de quelques
dizaines de milliers de lignes. L'enquête Emploi en compte plusieurs
centaines de milliers par trimestre.

*L'écosystème.* Python est gratuit, installé partout, et dispose de
bibliothèques matures pour charger, nettoyer, décrire, représenter et
modéliser des données.

Faut-il pour autant abandonner les autres outils ? Non. Le tableur reste
excellent pour regarder rapidement un petit fichier. Stata garde une longueur
d'avance sur certaines méthodes d'économétrie appliquée, et R sur la
statistique. Ce qui distingue Python, c'est sa polyvalence : le même langage
sert à récupérer les données, les traiter, les analyser et produire le
rapport. C'est aussi, très concrètement, la compétence la plus demandée sur
le marché du travail des économistes appliqués.

* Les variables

Une *variable* est un nom auquel on attache une valeur, pour pouvoir la
réutiliser. Le signe ~=~ ne signifie pas « égal » au sens mathématique : il
signifie « range cette valeur sous ce nom ».

#+BEGIN_SRC python
salaire_brut = 2500
taux_cotisation = 0.22

# On peut ensuite calculer à partir de ces noms.
cotisations = salaire_brut * taux_cotisation
salaire_net = salaire_brut - cotisations

print(salaire_net)
#+END_SRC

Lisez la troisième ligne de droite à gauche : Python calcule d'abord
=salaire_brut * taux_cotisation=, puis range le résultat sous le nom
=cotisations=. C'est pour cette raison qu'une ligne comme =x = x + 1= a un
sens en programmation alors qu'elle n'en a aucun en mathématiques.

Une variable peut être réaffectée : sa valeur change, et c'est la dernière
qui compte.

#+BEGIN_SRC python
salaire_brut = 2500
print(salaire_brut)

salaire_brut = 2800     # augmentation : l'ancienne valeur est perdue
print(salaire_brut)
#+END_SRC

** Nommer ses variables

Les règles imposées par Python sont peu nombreuses : un nom commence par une
lettre ou un tiret bas, ne contient ni espace ni accent ni tiret ordinaire, et
distingue les majuscules des minuscules (=salaire= et =Salaire= sont deux
variables différentes).

La règle qui compte vraiment n'est pas imposée par Python mais par le bon
sens : *un nom doit dire ce que la variable contient*. =s=, =x1= et =truc=
sont des noms légaux et de mauvais noms. =salaire_net_mensuel= est long, et
c'est très bien : on écrit un nom une fois, on le lit dix fois. La convention
en Python est de tout écrire en minuscules, les mots séparés par des tirets
bas.

#+BEGIN_SRC python
# Lisible
salaire_horaire = 12.5
heures_hebdomadaires = 35
salaire_hebdomadaire = salaire_horaire * heures_hebdomadaires
print(salaire_hebdomadaire)

# Le même calcul, illisible — et pourtant parfaitement valide
a = 12.5
b = 35
c = a * b
print(c)
#+END_SRC

* Les types de données

Toute valeur en Python a un *type*. Le type décide de ce qu'on a le droit de
faire avec la valeur. Quatre types suffisent pour aujourd'hui.

#+BEGIN_SRC python
age = 34                       # int   : nombre entier
salaire = 2187.50              # float : nombre décimal (le séparateur est un POINT)
diplome = "Master"             # str   : chaîne de caractères (string)
temps_plein = True             # bool  : booléen, True ou False

# La fonction type() révèle le type d'une valeur.
print(type(age))
print(type(salaire))
print(type(diplome))
print(type(temps_plein))
#+END_SRC

Trois pièges qui vous coûteront du temps si vous ne les repérez pas
maintenant.

Le *séparateur décimal est le point*, jamais la virgule : =2187.50= et non
=2187,50=. C'est une source d'erreurs constante quand on importe des données
françaises, et nous y reviendrons en séance 4.

Les booléens =True= et =False= prennent une *majuscule*, et ne sont pas entre
guillemets. =True= est une valeur logique ; ="True"= est un morceau de texte.

Enfin, =2500= et ="2500"= sont deux choses différentes : un nombre et un
texte. La cellule suivante le montre.

# Avec des nombres, + additionne.
print(2500 + 100)

# Avec du texte, + colle bout à bout. C'est la « concaténation ».
print("2500" + "100")

# Et mélanger les deux est une erreur. Décommentez pour voir le message :
# print("2500" + 100)

* Les opérations

Python calcule comme une calculatrice, avec trois opérateurs en plus.

#+BEGIN_SRC python
salaire_annuel = 2187.50 * 12

print(salaire_annuel)           # multiplication
print(salaire_annuel / 52)      # division  -> toujours un décimal
print(salaire_annuel // 1000)   # division entière -> le quotient, sans reste
print(salaire_annuel % 1000)    # modulo -> le reste de la division
print(1.02 ** 10)               # puissance -> 2 % par an pendant 10 ans
#+END_SRC

Les quatre opérations usuelles s'écrivent =+=, =-=, =*= et =/=. Attention :
la division =/= donne *toujours* un décimal, même quand elle tombe juste
(=8 / 2= vaut =4.0=, pas =4=).

Trois opérateurs sont plus spécifiques. La division entière =//= ne garde que
la partie entière du quotient. Le modulo =%= donne le *reste* : il sert à
tester la divisibilité, par exemple pour repérer les années de recensement.
La puissance =**= élève à un exposant, y compris fractionnaire — c'est ainsi
qu'on calcule un taux de croissance annuel moyen.

Les priorités sont celles des mathématiques : la multiplication et la division
passent avant l'addition et la soustraction, et les parenthèses tranchent.

#+BEGIN_SRC python
# Sans parenthèses, la multiplication passe d'abord.
print(1500 + 500 * 0.22)

# Avec parenthèses, la somme est calculée d'abord.
print((1500 + 500) * 0.22)
#+END_SRC

La fonction =round()= arrondit, ce qui est indispensable dès qu'on affiche un
montant.

#+BEGIN_SRC python
salaire_net = 2500 * (1 - 0.22)
print(salaire_net)
print(round(salaire_net, 2))    # 2 décimales
print(round(salaire_net))       # à l'euro
#+END_SRC

* Comparer : les booléens

Comparer deux valeurs produit un booléen, =True= ou =False=. C'est le
mécanisme sur lequel reposera tout le filtrage de données de la séance 4 :
« garder les femmes », « garder les salaires supérieurs au SMIC » sont des
comparaisons.

#+BEGIN_SRC python
salaire = 2187.50
smic = 1426.30

print(salaire > smic)      # strictement supérieur
print(salaire < smic)      # strictement inférieur
print(salaire >= smic)     # supérieur ou égal
print(salaire == 2187.50)  # ÉGAL : deux signes « = »
print(salaire != smic)     # différent

Retenez la distinction entre ~=~ et ~==~ : un seul signe *affecte* une valeur
à une variable, deux signes *comparent* deux valeurs. C'est l'erreur de
débutant la plus fréquente, et elle est silencieuse.

On combine les conditions avec =and=, =or= et =not=.

#+BEGIN_SRC python
salaire = 2187.50
temps_plein = True

# and : les deux conditions doivent être vraies
print(salaire > 2000 and temps_plein)

print(not temps_plein)

les concaténations, et éviteront de nombreuses erreurs de type.

* Application : du brut au net

Assemblons ce qui précède sur un cas concret. Le passage du brut au net est
une cascade de prélèvements : les cotisations salariales d'abord, le
prélèvement à la source ensuite.

#+BEGIN_SRC python
# Ordres de grandeur pour un salarié non cadre du privé.
salaire_brut = 2500.00
taux_cotisations = 0.22       # cotisations salariales
taux_prelevement = 0.05       # prélèvement à la source

cotisations = salaire_brut * taux_cotisations
net_avant_impot = salaire_brut - cotisations

impot = net_avant_impot * taux_prelevement
net_a_payer = net_avant_impot - impot

print(f"Brut               : {salaire_brut:8.2f} €")
print(f"Cotisations        : {cotisations:8.2f} €")
print(f"Net avant impôt    : {net_avant_impot:8.2f} €")
print(f"Prélèvement source : {impot:8.2f} €")
print(f"Net à payer        : {net_a_payer:8.2f} €")
print()
print(f"Taux de prélèvement global : {(1 - net_a_payer / salaire_brut) * 100:.1f} %")
#+END_SRC

Deux remarques. Le =8= dans ={cotisations:8.2f}= réserve huit caractères pour
le nombre, ce qui aligne la colonne des montants — un détail qui rend un
résultat lisible.

Surtout, notez que l'impôt porte sur le net avant impôt, pas sur le brut :
les prélèvements ne s'additionnent pas, ils se composent. C'est pour cela que
le taux global n'est pas 22 + 5 = 27 %. Cette distinction entre effets
additifs et multiplicatifs revient constamment en économie, et le code oblige
à la trancher explicitement.

* Application : les taux de croissance

Le second calcul qui reviendra sans cesse est le taux de croissance. Sa
définition est simple, mais deux erreurs sont si fréquentes qu'il vaut la
peine de les traiter dès maintenant.

#+BEGIN_SRC python
# Salaire net mensuel moyen dans le privé (ordres de grandeur INSEE).
salaire_2015 = 2250
salaire_2024 = 2735

# Taux de croissance sur l'ensemble de la période, en pourcentage.
croissance_totale = (salaire_2024 / salaire_2015 - 1) * 100
print(f"Croissance 2015-2024 : {croissance_totale:.1f} %")
#+END_SRC

Première erreur à éviter : diviser cette croissance totale par le nombre
d'années pour obtenir une croissance annuelle. Les taux de croissance se
*composent*, ils ne s'additionnent pas. Le taux annuel moyen est le taux
constant qui, appliqué chaque année, mènerait du point de départ au point
d'arrivée — c'est-à-dire une racine, donc une puissance fractionnaire.

#+BEGIN_SRC python
annees = 2024 - 2015

# FAUX : la moyenne arithmétique de la croissance totale
faux_taux = croissance_totale / annees

# JUSTE : le taux de croissance annuel moyen (géométrique)
taux_annuel = ((salaire_2024 / salaire_2015) ** (1 / annees) - 1) * 100

print(f"Approximation naïve : {faux_taux:.2f} % par an")
print(f"Taux annuel moyen   : {taux_annuel:.2f} % par an")
#+END_SRC

L'écart paraît faible ici parce que les taux sont petits ; il devient
considérable sur des séries longues ou volatiles.

Seconde erreur : confondre pourcentage et point de pourcentage. Si le taux de
chômage passe de 8 % à 7 %, il a baissé d'*un point*, mais de *12,5 %* en
valeur relative. Les deux énoncés sont vrais et ne disent pas la même chose.

#+BEGIN_SRC python
chomage_debut = 8.0
chomage_fin = 7.0

variation_points = chomage_fin - chomage_debut
variation_relative = (chomage_fin / chomage_debut - 1) * 100

print(f"Variation : {variation_points:+.1f} point de pourcentage")
print(f"Variation : {variation_relative:+.1f} % en valeur relative")
#+END_SRC

Le =+= dans ={variation_points:+.1f}= force l'affichage du signe, ce qui
évite toute ambiguïté sur le sens d'une variation.

* Mini-projet : fiche de paie simplifiée

Rassemblez la séance en un seul programme. Écrivez, dans la cellule
ci-dessous, un programme qui :

1. définit le salaire brut, le taux de cotisations et le taux de prélèvement
   à la source dans des variables clairement nommées ;
2. calcule les cotisations, le net avant impôt, l'impôt et le net à payer ;
3. affiche une fiche de paie alignée, à la manière de l'exemple du cours ;
4. affiche le salaire net annuel, prime de fin d'année comprise — comptez un
   treizième mois ;
5. indique enfin si le salaire net mensuel dépasse le salaire net médian
   français, que l'on prendra à 2 100 €.

/Bonus/ : faites en sorte que le programme demande le salaire brut à
l'utilisateur avec =input()=, plutôt que de le fixer en dur.

#+BEGIN_SRC python :corrige t
# --- Paramètres -------------------------------------------------------
salaire_brut = 2500.00
taux_cotisations = 0.22
taux_prelevement = 0.05
salaire_median = 2100

# --- Calculs ----------------------------------------------------------
cotisations = salaire_brut * taux_cotisations
net_avant_impot = salaire_brut - cotisations
impot = net_avant_impot * taux_prelevement
net_a_payer = net_avant_impot - impot

net_annuel = net_a_payer * 13          # 12 mois + treizième mois

# --- Affichage --------------------------------------------------------
print("=" * 38)
print("           FICHE DE PAIE")
print("=" * 38)
print(f"Salaire brut       : {salaire_brut:9.2f} €")
print(f"Cotisations        : {-cotisations:9.2f} €")
print(f"Net avant impôt    : {net_avant_impot:9.2f} €")
print(f"Prélèvement source : {-impot:9.2f} €")
print("-" * 38)
print(f"NET À PAYER        : {net_a_payer:9.2f} €")
print("=" * 38)
print(f"Net annuel (13 mois) : {net_annuel:.2f} €")

if net_a_payer > salaire_median:
    ecart = (net_a_payer / salaire_median - 1) * 100
    print(f"Au-dessus du salaire médian de {ecart:.1f} %.")
else:
    ecart = (1 - net_a_payer / salaire_median) * 100
    print(f"En dessous du salaire médian de {ecart:.1f} %.")

* Ce qu'il faut retenir

- Une *variable* est un nom attaché à une valeur ; ~=~ affecte, ~==~ compare.
- Toute valeur a un *type* : =int=, =float=, =str=, =bool=. Le séparateur
  décimal est le point, et une valeur venue de l'extérieur arrive en texte.
- Les *f-strings* (=f"… {variable:.2f} …"=) sont la bonne façon d'afficher un
  résultat.
- Les taux de croissance se *composent* : on passe par des puissances
  fractionnaires, jamais par une division du taux total.
- Un *point de pourcentage* n'est pas un *pourcentage*.
